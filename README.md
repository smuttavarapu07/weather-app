# Weather App 🌦️

A responsive single-page Weather Application built using React that allows users to search for a city and view its current weather information.

## Features

- **City Search:** Search for weather information by city name.
- **Current Temperature:** Display the temperature of the searched city.
- **Humidity Information:** View the current humidity level.
- **Weather Conditions:** Display conditions such as sunny, cloudy, or rainy.
- **Dynamic Background:** Change the background color based on weather conditions or temperature.
- **React State Management:** Use React `useState` to manage search input and weather data.
- **API Integration:** Fetch current weather information from a public weather API.
- **Responsive Design:** Provide a user-friendly interface across desktop and mobile devices.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Hooks (`useState` and `useEffect`)
- Weather API (such as OpenWeatherMap)

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## API Configuration

This project can use a public weather API or a local mock JSON file.

If using OpenWeatherMap, obtain an API key and configure it according to the project's implementation. Do not commit private API keys to GitHub.
